# 確率共鳴の比較実験 v2.0.0

モンテカルロ、Kramers多状態モデル、Fokker–Planck法を同じ外力・ノイズ条件で比較する日本語Streamlitアプリです。ピークを必ず出す処理や、欠測値を0に置き換える処理はありません。

## 起動

このフォルダの中で実行します。以前の `stochastic_resonance` フォルダと `.venv` は変更しません。

```bash
uv sync --python 3.12 --extra fast
uv run streamlit run app.py
```

`http://127.0.0.1:8501` を開きます。終了はターミナルで `Ctrl+C` です。`.python-version` と `pyproject.toml` を同梱しているため、ホームディレクトリにある別プロジェクトのPython要件を使う必要はありません。

Numbaによる高速化を使わない場合:

```bash
uv sync --python 3.12
uv run streamlit run app.py
```

通常のPython環境でも起動できます。

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## 使い方

「実験」で **3手法で解析** を押すと、粗探索と候補近傍の細分化を実行します。「独立試行・収束検証も実行」を選ぶと、同じボタンで確認試験まで進みます。

「系の比較」では、4種類の系、障壁の高さ、非対称性、障壁数、障壁間の高さ差を一括比較できます。観測量、外力、時間刻み、観測時間、ノイズ探索範囲、Welch帯域は共通です。単安定では井戸状態qを定義できないためxを使い、図の凡例と条件表に明示します。

「弱・候補・強の時系列を比較」で3つのノイズ条件を並べられます。「時系列・確率密度を計算」では、時系列、PSD、周期駆動FP密度、平均応答、Kramers率、滞在時間を表示します。

「検証」で候補を独立乱数で調べ直し、時間刻み・観測時間・FP格子・領域を変えた結果を確認できます。数式の数値代入は「数式・手法」にあります。

## 3手法の違い

| 手法 | 計算しているもの | 主な制約 |
|---|---|---|
| モンテカルロ | Euler–Maruyamaの確率軌道、Welch PSD、位相同期成分 | 標本誤差、有限時間、時間刻み |
| Kramers | 隣接井戸間の遷移率、多状態マスター方程式、線形応答SNR | 弱ノイズ・高障壁・遅い外力、井戸内運動の省略 |
| Fokker–Planck | 有限体積離散化、平衡雑音スペクトル、線形応答SNR、周期駆動確率密度 | 空間・時間離散化、有限領域、SNRの弱外力近似 |

**FP・KramersのSNR掃引は弱外力の線形応答です。** 一方、FPの密度表示とKramersの人口動態は周期外力を入れて直接時間発展させます。密度の平均波形だけでSNRを作る実装ではありません。非線形・有限振幅の厳密な周期定常相関からSNRを求める機能は未実装です。

FPでは有限領域の両端を反射境界とし、Scharfetter–Gummelの隣接セル流束を用います。離散定常分布は `p_i ∝ exp(-U_i/D)` です。時間発展は後退Euler法で、質量誤差・負の確率・周期間残差・端部確率を記録します。区間端のセル確率が十分小さいか、領域を広げても結果が変わらないかを確認してください。

Kramersでは各山の左右にある谷を検出し、**隣接井戸ごと**に率を計算します。三重井戸を無理に二状態にしません。単安定、平坦な極値、外力によって井戸構造が変化する条件は適用外です。分岐判定には `U''(x)=0` における臨界外力 `F=U'(x)` も用います。

## 数値積分と再現性

使用するSDEは

\[
dX_t=[-U'(X_t)+A\cos(2\pi f t)]dt+\sqrt{2D}\,dW_t.
\]

Euler–Maruyamaでは `sqrt(2 D dt) × N(0,1)` を加えます。駆動周期とFFT binを整合させるため、実際の時間刻みを `dt_actual = 1 / (f ceil(1/(f dt_requested)))` とします。指定より大きい刻みにはしません。

過渡周期を除外し、終端の重複サンプルを使わず、整数周期の記録を解析します。試行ごとに独立した `SeedSequence` を使い、Dと実験段階も乱数ストリームに組み込みます。試行数を増やしても先頭の試行の系列は変わりません。同じD・同じ段階の系同士には共通乱数を使用します。モデルごとのCIは独立試行間のばらつきに基づきますが、モデル間の推定値は独立ではありません。

Numbaの有無で同じ乱数を使います。発散した軌道を切り詰めて成功扱いにする処理はありません。大きなdtで発散した場合はエラーとし、計算条件を変更します。

## S/N比の定義

Welch法は周期Hann窓、50%重複、区間平均除去、片側PSD、`scaling="density"`、ゼロ埋めなしです。駆動周波数の周囲を信号帯域、その外側を雑音床の推定帯域とし、DC・ガード区間・高調波近傍を除きます。

周波数間隔をΔν、信号bin集合をB_S、雑音bin集合をB_Nとすると

\[
B=|B_S|\Delta\nu,\qquad
P_{N,j}=B\frac1{|B_N|}\sum_{k\in B_N}\widehat S_j(\nu_k).
\]

### 標準: 同期成分 / 局所雑音床

各独立試行を既知の駆動周波数に射影します。

\[
z_j=\frac{2}{N_t}\sum_n g_j(t_n)e^{-i\Omega t_n},\qquad
\widehat P_{coh}=
\frac{|\sum_jz_j|^2-\sum_j|z_j|^2}{2N_{MC}(N_{MC}-1)}.
\]

\[
\mathrm{SNR}_{coh}=\frac{\max(\widehat P_{coh},0)}{\overline P_N}.
\]

異なる試行間の積を使うため、有限試行数による同期パワーの正のバイアスを取り除けます。PSDの最大binを探す方法ではありません。雑音床が周波数とともに傾く場合に、帯域パワーから一定床を引くだけで生じる歪みを避ける選択肢です。雑音床自体は近傍帯域の推定なので、帯域依存性は残ります。

95%CIは、試行を1本ずつ除くjackknifeで比の標準誤差を求め、t分布で近似します。負の同期パワー推定は点表示では0に制限しますが、差の検定には切り捨て前の符号付き推定量を使います。低信号・少数試行での名目被覆率は保証されません。

### 代替1: 平均PSDから計算

\[
P_{B,j}=\sum_{k\in B_S}\widehat S_j(\nu_k)\Delta\nu,\quad
\mathrm{SNR}_{pool}=
\frac{\max(\overline P_B-\overline P_N,0)}{\overline P_N}.
\]

### 代替2: 各試行SNRの算術平均

\[
\mathrm{SNR}_j=\frac{\max(P_{B,j}-P_{N,j},0)}{P_{N,j}},\qquad
\overline{\mathrm{SNR}}=\frac1{N_{MC}}\sum_j\mathrm{SNR}_j.
\]

この2つの95%CIは試行単位のpercentile bootstrapです。算術平均と平均PSDの比は異なる推定量です。未定義の試行だけを除外して平均する処理はしません。全試行で雑音床が0なら、平均PSDのSNRも未定義です。

SNRは無次元、dBは `10 log10(SNR)` です。0は−∞ dBに対応し、グラフでは欠測表示になります。CSVには元の線形値も保存します。

## FP・KramersのSNR

列生成行列をQ、定常確率をp₀、観測量をgとし、以下を解きます。

\[
(i\Omega I-Q_0)p_1=Q_Fp_0,\qquad\chi_g=g^Tp_1.
\]

\[
S_{g,0}^{(1)}(\nu)=4\Re\{g_c^T(i2\pi\nu I-Q_0)^{-1}(p_0\odot g_c)\},
\quad g_c=g-\langle g\rangle_0.
\]

同期パワーは `A²|χ|²/2`、雑音パワーはMCと同じ帯域幅・雑音binから計算します。FPとKramersの線は信頼区間ではありません。数値誤差と近似の妥当性は別に確認する必要があります。

## 共鳴の根拠と限界

探索の最大点D*は、**調べた候補値の中での最大**です。真の連続最適値や、全条件での最適値ではありません。候補付近を細分化しても、隣接Dの差が有意になるとは限りません。

確認試験は探索に使っていない乱数段階で、候補・低D端・高D端・A=0を再計算します。候補が両端およびA=0対照を上回るか、3つの片側差を検定します。標準推定量ではjackknife標準誤差のWelch型t近似、帯域差分ではbootstrap差を使用します。**1モデル内の3比較**にBonferroni補正を適用し、名目全体α=0.05とします。複数モデル・複数指標全体への同時保証ではありません。

「独立試行でピークを支持」は、指定した観測量・推定量・帯域・探索範囲での統計的な支持です。すべての系に共鳴が起きることや、現実の物理系で同じ応答が起きることの証明ではありません。

時間刻み半減と観測時間倍増ではCIの重なり、FP格子細分化と領域拡大ではSNR変化5%以内を診断基準にしています。これらは厳密な収束証明・同等性検定ではありません。周期駆動FPの時間刻み収束は、詳細表示のdt_FPを変えて別途確認します。

Kramers診断の `ΔU/D ≥ 5`、`Ω/min U'' ≤ 0.1`、`A max|x_b−x_m|/D ≤ 0.3` は明示した実用上の目安です。FP線形応答の外力診断も目安です。近似条件を満たしていない曲線を「理論的な証明」として使わないでください。

半周期整合 `τ_K ≈ 1/(2f)` は機構の目安であり、SNR最大化と同義ではありません。多井戸の平均脱出時間は `1 / Σ_j r_ij` です。1本の遷移率の逆数は一般に方向別の平均初通過時間ではありません。

## 井戸状態・遷移・ポテンシャル比較

SNR用のq(x)は、静的な障壁位置で区切る記憶なしの状態番号です。FPでも同じ観測量を使えます。従来版のヒステリシス付きq(t)とは違います。時系列の遷移数・滞在時間には別にcore-to-core判定を使い、最初と最後の打切り区間を除きます。完結区間だけの平均には有限観測による選択バイアスがあり、平均初通過時間の不偏推定ではありません。

障壁数指定のモデルは、Chebyshev多項式T_nを使った

\[
U(x)=hT_n(x/s)^2\{1+\gamma x/s+(\gamma x/s)^2/2\}+cx
\]

です。γ=c=0ではn個の谷、n−1個の同じ高さhの山があります。平均井戸間隔を固定していますが、局所曲率や全体の広がりはnとともに変わります。「山の数だけの純粋な因果効果」とはみなしません。実際の極値と方向別障壁高を毎回計算します。

単安定・線形・加法白色雑音は比較対照です。このモデルにピークがないことを、乗法雑音などを含むあらゆる単安定系への結論にはしません。
